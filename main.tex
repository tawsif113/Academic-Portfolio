\section*{Research Experience}

\projectentry{A Reproducible Privacy--Utility Audit for ML-Based Network Intrusion Detection}
{2026 -- Present}{Independent Research Project}
\begin{itemize}
  \item Designed a locked NSL-KDD binary-classification protocol with a
  70/10/20 target-train/validation/shadow split, validation-only threshold
  selection, and untouched KDDTest+ utility evaluation.

  \item Established archived Random Forest, XGBoost, and MLP IDS baselines. In
  the pre-MIA comparison, the validation-selected MLP threshold of 0.28
  produced 76.91\% Recall, 23.09\% FNR, and 84.08\% F1 on KDDTest+.

  \item Built five shadow MLPs and evaluated score-only black-box and
  label-aware audit threat models. The strongest overall held-out attack
  remained near chance (ROC-AUC $\approx 0.503$), so I treat the floor effect
  as a limitation, not as evidence that the model is private.

  \item Rebuilt the target MLP in PyTorch and completed one Opacus DP-SGD
  feasibility run with explicit accounting
  ($\varepsilon \approx 8.0$, $\delta=1.13\times10^{-5}$). It achieved 66.20\%
  Recall, 33.80\% FNR, 76.80\% F1, and 91.93\% PR-AUC; this run validates the
  implementation, not reduced membership leakage.

  \item In progress: privacy-budget sweep, the same fixed membership audit for
  each DP condition, bootstrap uncertainty, and repeated runs for selected
  settings.
\end{itemize}
